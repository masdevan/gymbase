## About

GymBase is a modern landing page concept designed for gyms, fitness centers, and personal trainers. Built with a focus on performance, responsiveness, and clean visual presentation, it provides an engaging digital experience for fitness brands looking to establish a professional online presence.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- GSAP
